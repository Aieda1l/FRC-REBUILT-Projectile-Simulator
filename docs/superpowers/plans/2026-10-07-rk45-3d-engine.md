# Milestone 2 RK4/RK45 3-D Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the duplicated 2-D projectile integrators with matching Python and JavaScript 3-D physics cores that support true RK4, adaptive Dormand-Prince RK45, wind, robot velocity, arbitrary spin axes, and interpolated crossings while preserving the existing UI and legacy API.

**Architecture:** Python and JavaScript implement the same nine-element state and pure derivative equations. The existing Python simulator and React UI become adapters over those cores; Python-generated golden fixtures pin cross-language parity without making the browser depend on the server.

**Tech Stack:** Python 3.11+, NumPy, FastAPI/Pydantic, JavaScript ES modules, Node 20 built-in `node:test`, React 19, Vite 7, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-07-rk45-3d-engine-design.md`

## Global Constraints

- Coordinate system is right-handed: x = forward/downrange, y = left lateral, z = up.
- Canonical state order is exactly `[x, y, z, vx, vy, vz, omega_x, omega_y, omega_z]`.
- Preserve Milestone 1 FUEL defaults: mass `0.215 kg`, radius `0.075 m`, `Cd=0.47`, lift cap `Cl=0.25`, air density `1.204 kg/m^3`, gravity `9.81 m/s^2`.
- Do not add a Reynolds-dependent drag law, new empirical lift law, or guessed FUEL spin-decay constant.
- Positive legacy backspin maps to 3-D spin `(0, -omega, 0)`.
- Drag and Magnus use air-relative velocity `u = v - wind`.
- Only spin perpendicular to airflow contributes to Magnus lift.
- Unconfigured spin decay is zero; configured `tau` must be positive and is integrated as `domega/dt = -omega/tau`.
- Supported core solvers are exactly `rk4` and `rk45`; legacy `euler` becomes an explicit error.
- Ground and target-height crossings use linear interpolation between accepted states; target-height entry is descending-only.
- Legacy `POST /api/simulate` request/response compatibility must be preserved.
- Existing 2-D UI controls and SVG projection remain visually unchanged in this milestone.
- JavaScript must use no new test framework dependency; use Node's built-in `node:test`.
- Before implementation, bring `milestone-2-rk45-3d-engine` up to date with `master` without dropping its existing red test/spec commits.

## Review Focus

- **Malformed/non-finite vectors and state arrays:** reject wrong lengths, NaN, and infinity before integration; pinned in Task 1 validation tests.
- **Near-zero air-relative velocity or perpendicular spin:** produce finite zero aerodynamic force rather than divide by zero; pinned in Task 1 force tests.
- **Ascending target-height crossing:** must not count as an entry event; pinned in Task 4 legacy target tests and Task 2 crossing-direction tests.
- **RK45 tolerance failure at minimum step:** must raise a deterministic integration error instead of looping; pinned in Task 3 adaptive-failure test.
- **Legacy compatibility under new coordinates:** existing 2-D API points, target-hit behavior, optimizer calls, and environment density must remain compatible; pinned in Tasks 4, 5, and 8.
